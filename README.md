# QuantScout — презентация

## Офлайн
Распакуйте весь ZIP в одну папку и откройте index.html в браузере.
Интернет и установка программ не нужны. Сохраняйте папку assets рядом с index.html.

## GitHub Pages
Загрузите содержимое архива (не сам ZIP) в корень репозитория.
В Settings → Pages выберите Deploy from a branch, ветку main и / (root), затем Save.
После публикации GitHub покажет адрес сайта.

Включены все макеты, палитры, увеличение изображений и сравнение цветов.
